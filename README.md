# EZENG — Học Phản Xạ Cùng AI

Ứng dụng web luyện phản xạ 4 kỹ năng tiếng Anh (Nghe, Nói, Đọc, Viết) nhanh gọn, thực tế và hiệu quả.

## Tính năng chính
- **🎧 Listening (Nghe hiểu)**: Nghe phát âm đoạn hội thoại ngắn qua Web Speech API và làm bài trắc nghiệm.
- **🎙️ Speaking (Luyện nói)**: Nhận diện giọng nói qua Micro bằng Speech Recognition và đánh giá cơ bản bài nói.
- **📖 Reading (Đọc hiểu)**: Đọc đoạn văn ngắn, mở rộng từ vựng hữu ích và trả lời câu hỏi đọc hiểu.
- **✍️ Writing (Luyện viết)**: Viết câu trả lời theo chủ đề và nhận gợi ý sửa bài theo từ khóa.
- **📊 Theo dõi tiến trình**: Tự động lưu tiến độ học tập và điểm số trực tiếp trên trình duyệt qua LocalStorage.

## Cách chạy ứng dụng
Chỉ cần mở trực tiếp file `index.html` bằng bất kỳ trình duyệt web hiện đại nào (Chrome, Edge, Firefox, Safari).
